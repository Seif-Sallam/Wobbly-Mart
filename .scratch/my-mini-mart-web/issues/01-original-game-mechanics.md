## Question

What exactly does My Mini Mart contain and how does it play — core loop, every station/crop/animal/product, staff, customers, upgrades, expansions, progression, idle/offline earnings, camera/UI/"feel" — plus a first look at GitHub Pages limits and browser 3D tech options?

Findings: `.scratch/my-mini-mart-web/research/01-game-and-hosting.md`.

## Answer

Catalog written to `research/01-game-and-hosting.md` (sourced; gaps marked [UNVERIFIED]/[NOT FOUND]).
- Dev Kiseki Games, publisher Supersonic; 100M+ installs. Closest web analogue: Monkey Mart (Poki).
- Loop: one character, joystick/slide; proximity does everything — harvest → carry stack → stock shelf → checkout → collect cash pile. Buy by standing on floor price pads; camera pans to the next unlock; arrow-only tutorial.
- Opening: cash box → tomato shelf → tomato bed → egg shelf → chicken coop (fed tomatoes) → blender (ketchup) → expansions/extra shelves. Later: wheat/flour/bread, cows/milk, apples, sugar, cookies, coffee, jam.
- Staff: cashier, shelver, farmer, chefs; speed/capacity upgrades. Original staff AI is weak — opportunity.
- Multiple themed marts with completion %, star rating, prestige rebuild; side events (thief, delivery orders).
- No published numbers for spawn rates, patience, tips, offline earnings.
- Hosting: GitHub Pages fine (1 GB site, 100 GB/mo soft, HTTPS, no custom headers). Tech lean: Three.js + Vite.
